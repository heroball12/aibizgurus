# Conversation types

| Type | Default length | Assumption |
|---|---|---|
| Cold | Short | No prior conversation. Offer a plausible opportunity without claiming an observed problem. |
| Decision maker — requested information | Standard | A real conversation occurred. Prioritize specific recent notes and the requested information. |
| Gatekeeper — requested information | Short | Spoke with a gatekeeper, not necessarily the intended recipient. Keep it easy to forward; never imply endorsement. |
| Follow-up | Short | Find a useful next step in recent activity and emails manually marked sent. Generated drafts are not evidence of contact. |

Managers can change labels, availability, type guidance and default length. A global default length can override the type defaults. Protected policy always takes precedence.

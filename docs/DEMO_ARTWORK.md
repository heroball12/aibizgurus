# Demo character artwork

Final portraits are JPEG exports of generated reference images; the same files provision Runway with `imageProcessing: none`. All characters have sealed graphite helmets, a purple visor, gold accents and industry clothing. Feminine designs add external hair without exposing facial features. The educator is named Mira in the product; the working name in her image brief was Remy.

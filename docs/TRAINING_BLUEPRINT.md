## Phase 1 implementation and sensible defaults

- Real models and staff routes; no front-end-only completion mockup. Employee and manager views use persisted evidence.
- Server-graded quizzes with nonce protection and explanatory history; saved typed practice with linked retries and manager scoring. Optional AI advisory feedback must cite learner evidence and cannot certify.
- Guru TEACH, QUIZ, ROLE-PLAY, COACH, RETEST and RECOMMEND modes reuse existing Runway sessions and the shared quiet-voice/turn-taking interface.
- **PROPOSED** thresholds: 80% quiz, 8/10 reviewed role-play without critical failure, 90% distinct video coverage. Track admin fields make these configurable; historical attempts retain their policy snapshot.
- Training/shadowing/supervised/independent phases; manager practical + CRM demonstration + capstone + final sign-off. Retraining preserves old records and revokes the current award.
- Owner-controlled Draft → Owner review → Approved → Published → Retired states. Approved content is immutable; revisions copy into Draft with asset-review flags cleared.
- Private persistent-disk and S3-compatible media integration, a verified-bundle importer and a player with captions, chapters, speed, resume and media-retry controls. Production hosting remains to be configured.

## Technical limitations and remaining acceptance

The local platform text-AI key is absent. Saved practice therefore identifies guided scripted rehearsal; no automatic score is fabricated. Adaptive text replies/advisory feedback are wired for the existing server credential when configured. Runway live coaching uses existing credentials but its newly scoped Academy session has not been exercised with a real call. Live coaching is separate from saved/scored written practice and manager-observed practicals; the app does not record microphone audio or analyze real calls.

The owner approved the Module 1 written package and pilot production on 2026-09-25, then accepted the corrected 74-second pilot using website Guru's verified Runway live Vincent voice on 2026-09-27. The owner also accepted the complete Module 1 film and authorized all remaining Core films. Full Module 1 uses that same voice and the owner's subsequent custom-pricing amendment; its measured edit is 16:14, including practice pauses. See the production log for final export QA. The owner requested a local delivery folder for a Render persistent disk. Local private range playback, seeking past five minutes, speed controls and phone layout have been checked. Production hosting and actual live Academy provider integration acceptance remain before employee publication. Long videos are edited programs built from short shots, not a single 15-minute generation. Production Render secrets were not inspected or changed.

The current CRM's saved assessment record is not an automatic calendar invitation. Public/demo features are not evidence of a customer's integration. Existing derived performance labels must not be taught as verified dial/contact metrics. Team video chat/screen sharing remain deferred.

Pricing alignment gap identified during training production: the legacy public catalog and website concierge still supply starting-price figures, and CRM pricing fields are not a qualification check for AI Specialists. This training revision does not change those public pages or CRM role permissions. The current Academy policy explicitly overrides legacy figures and prohibits SDR/Guru quotes; the public experience needs a separate consistency pass against the 2026-09-27 amendment.

Google Workspace

  1. In a Google Cloud project owned by your Workspace organization, enable the Gmail API. Configure an Internal OAuth audience and the app name/branding.
  2. Create a Web application OAuth client with this exact authorized redirect URI: {{ google_redirect }}.
  3. In Render Environment, set SALES_GOOGLE_CLIENT_ID, SALES_GOOGLE_CLIENT_SECRET, SALES_GOOGLE_REDIRECT_URI and SALES_GOOGLE_DOMAINS. Use a strong, persistent FIELD_ENCRYPTION_KEY; preserve the existing key if you already use encrypted integrations.
  4. Allow the app through Workspace API controls if your organization restricts third-party apps. Each employee then connects their mailbox here.

Company SMS

  1. Use a Twilio number enabled for SMS. Set TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, SALES_SMS_FROM_NUMBER (with country code), and PUBLIC_BASE_URL=https://aibiz.guru in Render. If using a Messaging Service, also set SALES_SMS_MESSAGING_SERVICE_SID and include that number in its sender pool.
  2. Set the number or Messaging Service’s incoming-message webhook to {{ sms_inbound_url }}, using HTTP POST. Use a sales number whose inbound routing can be dedicated to this feature.
  3. Complete the sender registration required by Twilio for your destination countries. Test sending, replies, delivery updates and STOP with a consenting internal recipient before prospect outreach.
